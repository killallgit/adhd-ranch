**Depth**: Standard — 30 requirements-quality questions.
**Audience / Timing**: Reviewer; requirements review before the next specification revision or acceptance discussion. Suitable for PR review, not a runtime test procedure.
**Input**: `$speckit-checklist` with no additional focus supplied; standard scope selected from the current spec, plan, and tasks.

**Note**: This custom checklist is generated by `$speckit-checklist` from feature context and requirements.

Creating this checklist grants no compliance result, exception, or Draft-status promotion.
